# 💻 Лабораторная работа №2 по предмету "Стандартизация Программного Обеспечения"
**Программа рассчёта метрики Джилба языка "GO"**

> ### 📥 [Скачать программу (.exe)](https://github.com/Kaz1mier/Lab2-StandardizationOfSoftwareTraining/releases/download/v1.0/Lab2.exe) 

---

## 📋 О проекте
Приложение созданное с помощью Windows forms на C#. На основе анализа программа рассчитывает метрики Джилба:
абсолютную сложность, относительную сложность, максимальную вложенность, общее число операторов. Результат работы программы - таблицы, в одной из которых отображаются операторы ветвления, а в другой операторы языка Go.

---

## 🎮 Инструкция по использованию

### Шаг 1. Нажмите кнопку "Открыть файл" и выберите файл с кодом на языке "GO"
---
### Шаг 2. Нажмите кнопку "Рассчитать метрики Джилба" и появится таблица оператора ветвления по Джилбу и оператороы по спецификации Go.
